# FreshMart Sri Lanka

FreshMart Sri Lanka is a fully static supermarket e-commerce website built with HTML, CSS, and vanilla JavaScript.

## Structure

- index.html - Home page
- products.html - Product catalog with search and category filter
- cart.html - Shopping cart page
- checkout.html - Checkout and WhatsApp ordering form
- css/style.css - Main stylesheet
- js/products.js - Product database and rendering helpers
- js/cart.js - Local storage cart logic
- js/checkout.js - Checkout and WhatsApp order flow

## How to use

Open index.html directly in a browser.

## GitHub Pages

Upload the FreshMart folder to GitHub and publish the repository via GitHub Pages.
